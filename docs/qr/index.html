    How to use it

    1. Say what the code should do

      Pick a type (Link, Wi-Fi, Contact…) and fill in the boxes. The preview updates while you type.

    2. Choose a look, if you like

      Change the pattern, the corners and the colors, or add your logo. You can skip this step: the default look scans perfectly.

    3. Download it, then test it

      Save the picture, open your phone's camera and point it at the code. If it opens the right thing, you are done.

    Before you print

    • Test the code with two different phones.
    • Keep the code dark and the background light. Light codes on dark backgrounds often fail.
    • Keep the white margin around the code. Scanners need it.
    • Print it at least 2 cm wide. For a poster, make it about one tenth of the distance people will scan from.
    • Use the SVG file for anything large. It never gets blurry.
    • A logo covers part of the code. If scanning gets slow, make the logo smaller.
    • Square corners are read by every scanner. Circle corners work with phone cameras, but some older scanner apps cannot read them.

    Good to know

    Will my QR code stop working one day?

    No. Your link or text is written directly into the picture. Nothing depends on this website: once you have downloaded the code it works forever, even if this page disappears.

    Why do some websites ask for money after a few days?

    Many “free” generators make dynamic codes. The code does not contain your link; it contains a link to their server, which then forwards people to you. When the free trial ends they switch the forwarding off and ask for a subscription, often after you have already printed the code. This tool only makes static codes, with nothing in the middle. You can check: the box “Inside your code” shows exactly what the code contains.

    Can I change where the code goes after I print it?

    No. That is the one thing a static code cannot do. To change the destination, make a new code. Tip: point the code at a page you control (your website, your link page) and change that page instead.

    Where does my information go?

    Nowhere. The code is made on your own phone or computer. What you type, and the logo you add, are never uploaded. There is no account, no tracking and no advertising.

    My code does not scan. What can I do?

    Try these in order: use a dark code color on a white background; choose Square corners and the Classic or Rounded pattern; make the logo smaller or remove it; shorten the content; print the code larger. And always leave the white margin around it.

    Can I use these codes for my business?

    Yes: on menus, flyers, packaging, business cards, anywhere. They are yours, with no limit on scans and nothing to pay.
